# Graph Card 기본 컬렉션

그래프 카드에서 사용할 수 있는 공개 기본 컬렉션입니다.

| 컬렉션 | 카드 | 원본 파일 |
| --- | ---: | --- |
| 수와 연산 | 25 | [collection.json](collections/math-numbers/collection.json) |
| 수학 기호 | 32 | [collection.json](collections/math-symbols/collection.json) |

각 컬렉션은 한국어, 영어, 일본어, 번체 중국어를 포함합니다. 그래프 카드의 **내 컬렉션 → 가져오기 → 링크**에 파일의 GitHub 주소를 붙여 넣어 가져올 수 있습니다.

원본을 수정할 때는 기존 컬렉션과 카드 ID를 유지하고 `contentVersion`을 갱신합니다.
